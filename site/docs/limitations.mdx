Grid Layout is being built. This page lists what is still missing and the order the next steps
come in.

## The roadmap

1. **Walking skeleton**: the layout rules, the model, the engine, the React primitives, the
   keyboard, right-to-left and the first examples.
2. **External drag and drop**: widgets dragged in from outside the grid, a toolbox, drop rules,
   files, dragging out to remove.
3. **Responsive and mobile**: breakpoints by container width, layouts per breakpoint, long-press
   touch, edge auto-scroll.
4. **Constraints, compactors and positioning**: pluggable constraints, aspect ratios, wrap and
   fast compactors, scaled containers, a grid background.
5. **Parity and gallery**: model API recipes, real-world apps and an audit against React Grid
   Layout.
