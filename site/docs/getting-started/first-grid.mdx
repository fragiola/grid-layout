<Steps>

<Step>

## Describe the layout

A layout is an array of items in grid units: `x` and `y` are the first column and row, `w` and
`h` the width and height in columns and rows. `id` names each item.

<Framework name="react">

```tsx title="layout.ts"
import type { Layout } from "@fragiola/grid-layout-react";

export const layout: Layout = [
    { id: "revenue", x: 0, y: 0, w: 4, h: 2 },
    { id: "orders", x: 4, y: 0, w: 4, h: 2 },
    { id: "visitors", x: 8, y: 0, w: 4, h: 2 },
];
```

</Framework>

<Framework name="vue">

```ts title="layout.ts"
import type { Layout } from "@fragiola/grid-layout-vue";

export const layout: Layout = [
    { id: "revenue", x: 0, y: 0, w: 4, h: 2 },
    { id: "orders", x: 4, y: 0, w: 4, h: 2 },
    { id: "visitors", x: 8, y: 0, w: 4, h: 2 },
];
```

</Framework>

<Framework name="angular">

```ts title="layout.ts"
import type { Layout } from "@fragiola/grid-layout-angular";

export const layout: Layout = [
    { id: "revenue", x: 0, y: 0, w: 4, h: 2 },
    { id: "orders", x: 4, y: 0, w: 4, h: 2 },
    { id: "visitors", x: 8, y: 0, w: 4, h: 2 },
];
```

</Framework>

## Render the grid

`Root` takes the layout and the grid's measurements; `Items` hands you each item to render. The
item is yours: put anything inside.

<Framework name="react">

```tsx title="dashboard.tsx"
import { GridLayout } from "@fragiola/grid-layout-react";

export function Dashboard() {
    return (
        <GridLayout.Root defaultLayout={layout} cols={12} rowHeight={64} gap={[12, 12]}>
            <GridLayout.Items>
                {(item) => (
                    <GridLayout.Item itemId={item.id} aria-label={item.id}>
                        {item.id}
                    </GridLayout.Item>
                )}
            </GridLayout.Items>
        </GridLayout.Root>
    );
}
```

</Framework>

<Framework name="vue">

In Vue, `Items` renders its default slot for each item (`v-slot="{ item }"`).

```vue title="dashboard.vue"
<script setup lang="ts">
import { GridLayout } from "@fragiola/grid-layout-vue";
import { layout } from "./layout";
</script>

<template>
    <GridLayout.Root :default-layout="layout" :cols="12" :row-height="64" :gap="[12, 12]">
        <GridLayout.Items v-slot="{ item }">
            <GridLayout.Item :item-id="item.id" :aria-label="item.id">
                {{ item.id }}
            </GridLayout.Item>
        </GridLayout.Items>
    </GridLayout.Root>
</template>
```

</Framework>

<Framework name="angular">

In Angular, each part is a directive on an element you write: `gridLayoutRoot` on the grid, and
an `<ng-template gridLayoutItems>` rendered once per item (`let-item`). `GRID_LAYOUT` lists every
directive for the component's `imports`.

```ts title="dashboard.ts"
import { Component } from "@angular/core";
import { GRID_LAYOUT } from "@fragiola/grid-layout-angular";
import { layout } from "./layout";

@Component({
    selector: "app-dashboard",
    imports: [GRID_LAYOUT],
    template: `
        <div gridLayoutRoot [defaultLayout]="layout" [cols]="12" [rowHeight]="64" [gap]="[12, 12]">
            <ng-template gridLayoutItems let-item>
                <div [gridLayoutItem]="item.id" [attr.aria-label]="item.id">{{ item.id }}</div>
            </ng-template>
        </div>
    `,
})
export class Dashboard {
    protected readonly layout = layout;
}
```

</Framework>

It already drags: press an item and move. It has no look: the next step gives it one.

</Step>

## Add a handle and a placeholder

A `ResizeHandle` is a side or corner the item is resized from; a `Placeholder` shows where the
held item would land. Neither has a look or a size of its own.

<Framework name="react">

```tsx title="dashboard.tsx"
<GridLayout.Item itemId={item.id} aria-label={item.id} className="card">
    {item.id}
    <GridLayout.ResizeHandle side="bottom-end" aria-label={`Resize ${item.id}`} className="corner" />
</GridLayout.Item>

<GridLayout.Placeholder className="placeholder" />
```

</Framework>

<Framework name="vue">

```vue title="dashboard.vue"
<GridLayout.Item :item-id="item.id" :aria-label="item.id" class="card">
    {{ item.id }}
    <GridLayout.ResizeHandle side="bottom-end" :aria-label="`Resize ${item.id}`" class="corner" />
</GridLayout.Item>

<GridLayout.Placeholder class="placeholder" />
```

</Framework>

<Framework name="angular">

The handle and the placeholder are rendered only at times (a handle while its item can be
resized, the placeholder during a gesture), so they are template directives: the `*` form on
your element.

```html title="dashboard.ts (template)"
<div [gridLayoutItem]="item.id" [attr.aria-label]="item.id" class="card">
    {{ item.id }}
    <div *gridLayoutResizeHandle="'bottom-end'" [attr.aria-label]="'Resize ' + item.id" class="corner"></div>
</div>

<div *gridLayoutPlaceholder class="placeholder"></div>
```

</Framework>

</Step>

<Step>

## Style the parts

Every part exposes its state as `data-*` attributes. In React, `className` also takes a function
of the state; in Vue, `class` takes a value, and the `data-*` attributes carry the state; in
Angular, the element is yours, and its `state()` signal is one `exportAs` away
(`#part="gridLayoutItem"`, `[class.held]="part.state().dragging"`).

```css title="dashboard.css"
.card { border: 1px solid #ddd; border-radius: 8px; background: white; cursor: grab; }
.card:not([data-dragging]) { transition: transform 160ms, width 160ms, height 160ms; }
.card[data-dragging] { cursor: grabbing; box-shadow: 0 12px 28px rgb(0 0 0 / 0.16); }
.corner { position: absolute; inset-inline-end: 0; bottom: 0; width: 14px; height: 14px; }
.placeholder { border: 2px dashed royalblue; border-radius: 8px; }
```

</Step>

<Step>

## Keep the changes

`onLayoutChange` (in Vue, `v-model:layout`; in Angular, `[(layout)]`) tells you the layout after every committed change, once: never during a
gesture. Save it, or hold the layout in your state and pass it as `layout`.

<Framework name="react">

```tsx title="dashboard.tsx"
const [layout, setLayout] = useState(start);

<GridLayout.Root layout={layout} onLayoutChange={setLayout}>…</GridLayout.Root>
```

</Framework>

<Framework name="vue">

```vue title="dashboard.vue"
<script setup lang="ts">
const layout = ref(start);
</script>

<template>
    <GridLayout.Root v-model:layout="layout">…</GridLayout.Root>
</template>
```

</Framework>

<Framework name="angular">

```ts title="dashboard.ts"
@Component({
    imports: [GRID_LAYOUT],
    template: `<div gridLayoutRoot [(layout)]="layout">…</div>`,
})
export class Dashboard {
    protected readonly layout = signal(start);
}
```

</Framework>

</Step>
