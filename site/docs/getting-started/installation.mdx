The core, `@fragiola/grid-layout`, comes along: import its types and helpers from your
framework's package, which re-exports it.

## Peer dependencies

| requirement | why |
| --- | --- |
| `react` and `react-dom` **^19** (React) | peer dependencies of `@fragiola/grid-layout-react`: the primitives use `ref` as a plain prop and ref cleanup functions |
| `vue` **^3.5** (Vue) | the peer dependency of `@fragiola/grid-layout-vue` |
| `@angular/core` **^22** (Angular) | the peer dependency of `@fragiola/grid-layout-angular`: standalone directives and signals, no zone.js needed |
| A browser DOM | the engine measures the root and its items; the model loads in plain Node (tests, a server) |

The packages have no other runtime dependency, and the core has none at all: no drag library, no
resize library.

## What to import from where

<Framework name="react">

```tsx
import {
    // the primitives (one namespace) and the hooks
    GridLayout,
    useGridLayout,
    // the core: its types and helpers
    type Layout,
    verticalCompactor,
} from "@fragiola/grid-layout-react";
```

</Framework>

<Framework name="vue">

```ts
import {
    // the components (one namespace) and the composables
    GridLayout,
    useGridLayout,
    // the core: its types and helpers
    type Layout,
    verticalCompactor,
} from "@fragiola/grid-layout-vue";
```

The components are the React package's primitives, written the Vue way (props, events, slots):
[Vue components](/docs/api/vue) maps each React prop.

</Framework>

<Framework name="angular">

```ts
import {
    // every directive, for a standalone component's `imports`, and the injection functions
    GRID_LAYOUT,
    injectGridLayout,
    // the core: its types and helpers
    type Layout,
    verticalCompactor,
} from "@fragiola/grid-layout-angular";
```

The directives are the React package's primitives, written the Angular way (directives on your
elements, inputs, outputs, templates): [Angular directives](/docs/api/angular) maps each React
prop.

</Framework>

## No stylesheet

There is nothing to import for styles. The primitives set only the inline style they need to work
(a position, a size, a transform). Style every part with your own classes and the `data-*`
attributes it exposes. See [Styling with Tailwind](/docs/guides/styling-tailwind) and
[Styling with plain CSS](/docs/guides/styling-css).

<Callout type="info" title="A width to lay out in">
`GridLayout.Root` measures its own width and places the items in it. Give it a width (or let it
fill its parent): its height follows the layout.
</Callout>
